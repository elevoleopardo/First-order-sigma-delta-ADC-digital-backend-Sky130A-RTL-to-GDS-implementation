# 02 — Architecture

## 1. System Overview

The project implements the digital backend of a first-order Sigma-Delta ADC.

The complete converter concept is divided into two main domains:

1. the Sigma-Delta modulation stage, which converts the analog input into a 1-bit high-frequency bitstream;
2. the digital decimation and filtering stage, which reconstructs a lower-rate multi-bit representation of the input signal.

During the digital development phase, the analog/modulator portion is represented by a behavioral model. This allows the digital backend to be designed and verified independently before integrating the physical analog circuitry.

The digital architecture is:

```text
                ANALOG / BEHAVIORAL DOMAIN

                         |
                         v
              +---------------------+
              | Sigma-Delta          |
              | 1st-order modulator  |
              | 1-bit quantizer      |
              +---------------------+
                         |
                         | 1-bit @ 5.12 MHz
                         v
                DIGITAL DOMAIN

              +---------------------+
              | CIC Decimator       |
              | sinc^3              |
              | R = 64              |
              +---------------------+
                         |
                         | 19-bit @ 80 kHz
                         v
              +---------------------+
              | FIR Compensation    |
              | 15 taps             |
              | decimation = 2      |
              +---------------------+
                         |
                         | 16-bit @ 40 kHz
                         v
                  Digital Output
2. Separation Between Analog and Digital Domains

The Sigma-Delta ADC fundamentally combines analog and digital functions.

The analog/modulator portion contains:

analog input;
integrator;
feedback DAC;
1-bit quantizer.

The digital portion contains:

CIC decimation filter;
FIR compensation filter;
output scaling;
output-valid generation.

For the current development stage, the modulator output is generated by the Python behavioral model rather than by the physical analog circuitry.

This separation allows the digital backend to be tested using a deterministic reference bitstream.

3. First-Order Sigma-Delta Modulator

The modulator is a first-order, single-bit Sigma-Delta architecture.

Conceptually, the loop contains an integrator followed by a 1-bit quantizer. The quantized output is fed back to the input through a 1-bit DAC.

A simplified representation is:

                    +-----------------------+
                    |                       |
                    |       1-bit DAC      |
                    |                       |
                    +----------<------------+
                               |
                               v
Input signal ---> (+) ---> [Integrator] ---> [1-bit Quantizer]
                  ^                              |
                  |                              |
                  +------------------------------+
                               |
                               v
                       1-bit bitstream

The quantizer produces only two possible output states.

In the behavioral model these states are represented using:

0 -> -1
1 -> +1

The high sampling frequency allows quantization noise to be shaped toward higher frequencies.

The subsequent digital filters remove the out-of-band quantization noise while reducing the sampling rate.

4. Oversampling

The signal bandwidth is 20 kHz, while the final output sampling frequency is 40 kHz.

The modulator operates at:

Fs_mod = 5.12 MHz

Therefore the oversampling ratio is:

OSR = Fs_mod / Fs_out
    = 5.12 MHz / 40 kHz
    = 128

The high-rate 1-bit stream therefore contains substantially more samples than are required at the final output rate.

The digital backend exploits this redundancy to perform noise filtering and decimation.

5. CIC Decimator

The first digital stage is a third-order CIC filter.

The implementation uses:

Number of stages N = 3
Decimation factor R = 64
Differential delay M = 1

The CIC structure can be represented as:

1-bit input
    |
    v
+-----------+
| Integrator|
|     x3    |
+-----------+
    |
    | /64
    v
+-----------+
|   Comb    |
|     x3    |
+-----------+
    |
    v
19-bit output @ 80 kHz

The three integrators operate at the full modulator rate.

After decimation by 64, the three comb sections operate at the lower rate.

The resulting transfer function has the characteristic form:

H(z) = [(1 - z^-R) / (1 - z^-1)]^N

with:

R = 64
N = 3

Therefore the response is proportional to a sinc^3 characteristic.

6. CIC Arithmetic

The input bitstream is converted from the one-bit representation to a bipolar numerical representation:

0 -> -1
1 -> +1

The integrator stages use finite-width arithmetic.

The selected internal width is:

CIC_W = 19 bit

The RTL intentionally allows the integrators to operate with wrap-around arithmetic.

This behavior is compatible with the modular arithmetic used by a CIC filter and avoids the need for additional overflow-management logic inside the integrator chain.

The comb stages operate on the decimated data.

7. Decimation by 64

The CIC reduces the sampling rate from:

5.12 MHz

to:

5.12 MHz / 64 = 80 kHz

The first stage therefore performs most of the required sampling-rate reduction.

The output of the CIC is a multi-bit signal with a 19-bit internal representation.

8. CIC Passband Droop

A CIC filter is attractive for hardware implementation because it requires only additions, delays and registers.

However, its frequency response is not flat in the passband.

The sinc^3 response introduces amplitude droop that becomes relevant within the 20 kHz signal band.

For this reason, a FIR compensation filter is placed after the CIC.

Conceptually:

Ideal response
----------------------------

CIC response
\___________________________
      passband droop

FIR compensation
/---------------------------

Combined response
----------------------------
approximately flat in band

The FIR is designed to compensate the amplitude distortion introduced by the CIC.

9. FIR Compensation Filter

The second filtering stage is a 15-tap FIR filter.

Its main parameters are:

NTAPS     = 15
D         = 2
COEF_BITS = 12
DIN_W     = 19
OUT_W     = 16

The FIR receives the 19-bit CIC output and produces the final 16-bit output.

The FIR also performs the remaining decimation by 2:

80 kHz / 2 = 40 kHz

Therefore the complete digital chain achieves:

5.12 MHz
    |
    | /64
    v
80 kHz
    |
    | /2
    v
40 kHz
10. Fixed FIR Coefficients

The FIR coefficients are fixed at synthesis time.

They are not supplied through an external interface and cannot be modified during normal operation.

The coefficient set is symmetric:

h[0]  = -3
h[1]  = -6
h[2]  = -14
h[3]  = -29
h[4]  = -51
h[5]  = -74
h[6]  = -93
h[7]  = 2047
h[8]  = -93
h[9]  = -74
h[10] = -51
h[11] = -29
h[12] = -14
h[13] = -6
h[14] = -3

Because:

h[k] = h[14-k]

the implementation can exploit coefficient symmetry.

Instead of computing fifteen independent products, the RTL computes eight multiplication terms:

h[0] x (x[0]  + x[14])
h[1] x (x[1]  + x[13])
h[2] x (x[2]  + x[12])
h[3] x (x[3]  + x[11])
h[4] x (x[4]  + x[10])
h[5] x (x[5]  + x[9])
h[6] x (x[6]  + x[8])
h[7] x  x[7]

This reduces the multiplier count and therefore the synthesized hardware complexity.

11. FIR Scaling and Saturation

The FIR accumulation is wider than the final output representation.

After accumulation, the result is scaled to the selected 16-bit output range.

The implementation includes saturation logic so that values outside the representable output range do not wrap around.

The processing can therefore be summarized as:

19-bit CIC output
       |
       v
FIR multiply-accumulate
       |
       v
Wide internal accumulator
       |
       v
Scaling
       |
       v
Saturation
       |
       v
16-bit output
12. Output Valid Signal

The digital backend does not produce a new output sample on every modulator clock.

The output-valid signal indicates when a new decimated output sample is available.

The effective output rate is:

Fs_out = 40 kHz

while the processing clock remains:

Fs_mod = 5.12 MHz

This allows the same system clock to drive the complete digital backend while the output samples are produced at the lower decimated rate.

14. Architectural Design Choice

The architecture intentionally separates the computationally intensive sampling-rate reduction from the passband compensation.

The CIC performs the large decimation factor with adders and registers, avoiding multipliers at the highest sampling frequency.

The FIR operates only after the signal has already been reduced from 5.12 MHz to 80 kHz.

This results in a more hardware-efficient structure:

High rate                     Low rate

5.12 MHz                      80 kHz
   |                              |
   | CIC                          | FIR
   | adders/registers             | multipliers
   | /64                          | /2
   v                              v
80 kHz                          40 kHz

This architecture is particularly suitable for an ASIC implementation where unnecessary high-frequency multiplier activity would increase area and switching activity.

15. Current Architecture Boundary

The current hardened block begins at the 1-bit Sigma-Delta bitstream.

Therefore:

Analog input
     |
     v
Sigma-Delta modulator
     |
     |  <-- boundary of current digital core
     v
adc_sd_top
     |
     v
CIC + FIR
     |
     v
16-bit digital output

The physical analog Sigma-Delta front-end is not part of the current hardened digital macro.

The Python model provides the behavioral stimulus needed to validate the digital backend.

16. Future Integration
