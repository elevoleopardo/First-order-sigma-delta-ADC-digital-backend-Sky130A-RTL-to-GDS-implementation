# First-Order Sigma-Delta ADC — Sky130A

Digital backend implementation of a first-order Sigma-Delta ADC developed as part of the PSEI project / thesis in Electronic Engineering.

The project covers the complete digital design flow, from the behavioral golden model to RTL verification, synthesis, place & route and ASIC signoff in the Sky130A technology.

## Project Status

Current status:

TinyTapeout integration is considered a subsequent stage and is kept separate from the validated core implementation.

## Architecture

The digital backend receives the 1-bit bitstream generated by the Sigma-Delta modulator.

The processing chain is:

```text
1-bit Sigma-Delta bitstream
            |
            v
    +----------------+
    | CIC Decimator  |
    | sinc^3 / 64    |
    +----------------+
            |
            v
    +----------------+
    | FIR Compensation|
    | 15 taps, /2    |
    +----------------+
            |
            v
       16-bit output
The CIC performs the main decimation from 5.12 MHz to 80 kHz.

The FIR compensation filter performs the final /2 decimation, producing the final 40 kHz output rate.

The FIR coefficients are fixed in hardware and are not programmable during operation.

Golden Model

The Python model provides the behavioral reference used to generate:

Sigma-Delta bitstream
CIC-decimated signal
FIR compensation coefficients
expected final output

The RTL output is compared against the golden output during simulation.

RTL

The RTL implementation consists of:

rtl/adc_sd_top.v — top-level ADC digital backend
rtl/cic_decimator.v — 3-stage CIC decimator
rtl/fir_comp.v — fixed-coefficient FIR compensation filter

The FIR uses symmetric coefficients, reducing the number of multiplications required by the implementation.

RTL Verification

The RTL is verified against the Python golden model using Icarus Verilog.

The validated configuration produced:

Output samples compared: 4160
Maximum error:           0 LSB
Mismatches (>2 LSB):     0
Result:                  PASS
ASIC Implementation

The design was synthesized and physically implemented using OpenLane with the Sky130A PDK.

The final hardened core has approximately:

Die area: 0.2532 mm²
Core area: 0.2356 mm²
Synthesized cells: 9,315
Total placed/routed cells: 30,197
Final utilization: 37.41%
Wire length: 206,356
Vias: 60,906

The final implementation passed:

DRC
LVS
STA setup checks
hold checks
routing checks

The reported critical-path value is approximately 196.3 ns, while the detailed signoff timing report shows positive setup slack on the final implementation.

TinyTapeout

TinyTapeout integration is not yet part of the current hardened core.

The next stage is to develop a TinyTapeout-compatible wrapper and verify:

GPIO mapping
clock and reset interface
input/output serialization
tile dimensions
required physical layers
GDS/LEF integration
TinyTapeout-specific design rules

The current standalone Sky130A GDS should therefore not yet be considered a tapeout-ready TinyTapeout submission.
